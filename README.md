# Token Killer

English | [简体中文](README.zh-CN.md)

> Too many tokens? Waste them.
>
> Not sure how to use them well? Waste them anyway.

Token Killer is a browser-first token burner. Enter an endpoint, pick a model, set a budget, and it will keep making requests while carefully recording every gloriously pointless token spent.

[Try it online](https://pyxxxx.github.io/token-killer/) · [Deploy your own Token Killer](docs/deployment.md)

## Why this exists

As vibe coding becomes more popular, people have started treating token usage as a measure of engineering skill. It clearly is not.

In Token Killer, token usage says only one thing about you: how much you are willing to spend. 💰💰💰

The built-in leaderboard and rank system let you compete with developers around the world for the highly coveted title of Token Burning Champion. 👑

By default, the leaderboard connects to a service maintained by the project author. You can also follow the [deployment guide](docs/deployment.md) and run a leaderboard of your own.

## What it can do

- Supports OpenAI Responses, Chat Completions, legacy Completions, Anthropic Messages, Gemini `generateContent`, and other common request formats.
- Fetches the model list from the endpoint you provide and uses the OpenRouter catalog as a pricing reference.
- Accepts either a token target or a monetary budget, then recalculates the remaining allowance after every `usage` receipt.
- Tracks daily and lifetime usage, estimated cost, request rounds, and run history.
- Generates share cards, calculates competitive ranks, and supports global, country, and regional leaderboards.
- Provides a natural English and Simplified Chinese interface, with matching project documentation.
- Encrypts API keys and OAuth credentials with a key generated by the browser.
- Runs as a static site, or pairs with Cloudflare Workers and other serverless platforms for leaderboards, regional rankings, and subscription OAuth.

## Subscription allowance going to waste? Easy.

If your monthly ChatGPT, Claude, Gemini, or Grok subscription still does not feel fully used, Token Killer includes OAuth entry points that let you connect your own paid subscription and squeeze every last bit of value out of it.

OAuth requires a separately deployed authorization service. The repository includes a Cloudflare Workers implementation. Login buttons stay disabled until a service URL is configured and its health check succeeds. See [Deploying the full service](docs/deployment.md#option-2-deploy-the-full-service).

The authorization parameters, token refresh flows, and upstream compatibility logic are based in part on [Wei-Shaw/sub2api](https://github.com/Wei-Shaw/sub2api). Thank you.

> [!WARNING]
> High-frequency, automated, or unusual traffic may trigger rate limits, abuse controls, subscription restrictions, or account suspension. Read and follow each provider's terms before using this project. Neither this project nor its operators are responsible for lost accounts or subscriptions.

OAuth credentials are stored in the user's own browser. Subscription requests pass through the configured Worker for token exchange and forwarding. The Worker handles credentials and prompts in memory while a request is running, but does not write account credentials to the leaderboard database. Gemini OAuth also requires your own Client ID and Client Secret.

## Let providers opt out

Token Killer adds a recognizable marker to its inference requests. If you do not want your relay or public API to be used by Token Killer, you can reject marked requests with an agreed structured error code. Once the client confirms the rejection, it disables that provider in the current browser.

[How to identify and block Token Killer traffic](docs/provider-blocking.md) documents the marker, rejection response, and gateway setup, with examples for [QuantumNous/new-api](https://github.com/QuantumNous/new-api) and [Wei-Shaw/sub2api](https://github.com/Wei-Shaw/sub2api).

The marker is a voluntary signal from cooperative clients. It is not a replacement for authentication, quotas, rate limits, or abuse detection on the server.

## Deploy your own Token Killer

The quickest route is to [fork this repository](https://github.com/PYXXXX/token-killer/fork). A GitHub Pages workflow is already included; enable Actions and Pages to get a static site of your own.

If you also want a private leaderboard, regional rankings, and subscription OAuth, deploy the included Cloudflare Worker and D1 database. Both paths are covered in the [deployment guide](docs/deployment.md).

| Deployment | Included | Good for |
| --- | --- | --- |
| GitHub Pages | API-key mode, browser statistics, ranks, and share cards | Getting a static instance online quickly |
| Cloudflare Workers + D1 | Everything above, plus leaderboards, regional rankings, and subscription OAuth | Operating a complete instance |

The Pages workflow lives at [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml). Once configured, every push to `main` automatically updates the site.

## Before you use it

### Token targets are estimates

No client can know the exact billable token count before a request finishes. Tokenization, hidden reasoning, cached input, and upstream implementation details all affect the result.

Token Killer runs requests sequentially, recalibrates the remaining budget from each `usage` response, and reduces the next output limit as it approaches the target. It avoids obviously oversized next rounds, but it does not pretend it can always land on the final token or cent exactly.

### Browser CORS restrictions

Static mode requires the target API to allow cross-origin browser requests. If the server does not expose the appropriate CORS headers, the browser may reject the call even when the endpoint and API key are correct.

### Credentials and privacy

API keys and OAuth credentials are encrypted with a non-exportable AES-GCM key generated by the browser. Never paste API keys, authorization codes, access tokens, refresh tokens, account IDs, or full prompts into issues, screenshots, terminal output, or public logs.

The leaderboard identifies participants with automatically generated numbers and never accepts custom display names. Regional ranking uses location metadata supplied by Cloudflare; the leaderboard database does not store raw IP addresses.

### Project affiliation

Token Killer is an unofficial open-source project. It is not affiliated with or endorsed by OpenAI, Anthropic, Google, xAI, OpenRouter, or any other model or relay provider. Their names are used only to describe compatibility.

## Run locally

Node.js 22 or newer is required.

```bash
git clone https://github.com/PYXXXX/token-killer.git
cd token-killer
npm install
npm run dev
```

Before submitting changes, run:

```bash
npm test
npm run lint
npm run build
```
